## Play
Open `index.html` in a browser.

## Rebuild
`index.html` is generated by `tools/build3d.js` from the original game in `tools/source/` (sky photos in `tools/maps/`, ship models in `tools/models/`).
Install the build dependencies once with `npm install` in `tools/pp`, then run `node tools/build3d.js`; it writes `GAME.html` next to the `tools` folder.

## Audio
Sound effects: Kenney "Sci-Fi Sounds" (CC0). Music playlists come from `tools/audio/music/<menu|battle|boss>_*`; `node tools/audio/compose.js` regenerates the procedural tracks. See `tools/audio/CREDITS.md`.
